# KGEN Lead CRM

Internal CRM for booking-page leads. Frontend on GitHub Pages, data in Supabase (project `kgen-crm`, tables `crm_leads` / `crm_activities`, storage bucket `screenshots`).

Live: https://kgenagency.github.io/kgen-leads/

Leads flow in automatically: Slack #kgen-booking → Zapier → Supabase → here.
